# FlowCanvas Studio

A clean, interactive web-based flowchart designer for creating and presenting workflows.

> **Note:** This is my personal project built with the help of AI for learning and exploring web development.

## Features

- **7 Flowchart Blocks:** Start/End, Process, Decision, Database, Document, Input/Output, and Sticky Note.
- **Auto-Sizing Boxes:** Blocks automatically resize and wrap text so content never overflows.
- **Smart Flow Lines:** Connect blocks smoothly with Step (orthogonal), Curved, or Direct connectors.
- **Presentation Mode:** Step-by-step interactive walkthrough of your flowchart.
- **Import & Export:** Export diagrams as PNG, SVG, or JSON files.
- **Privacy & Memory Friendly:** Automatically clears temporary browser storage when you exit the page.
