# Flowchart App 🚀

## 👤 Author

* **Rishabh** - [@rishabh-py3](https://github.com/rishabh-py3)

An interactive web-based algorithm designer that allows users to create, visualize, and structure logic workflows using intuitive flowchart components.

> **Status:** ⚠️ **Beta Phase**  
> This project is under active development. You may encounter bugs, layout quirks, or missing functionality as updates are rolled out.

---

## 🌟 Key Features

* **Drag-and-Drop Canvas:** Place core flowchart components (Start/End, Process, Decision, Input/Output) on the canvas.
* **Visual Algorithm Mapping:** Graphically translate code logic and pseudocode into structured visual steps.
* **Dynamic Connectors:** Link nodes together to build execution paths and conditional logic loops.

---

## ⚠️ Known Issues & Work-in-Progress

Since this application is currently in early **Beta**, we are actively tracking and addressing the following known limitations:

* **Canvas Resizing:** UI components may shift or misalign when changing browser dimensions.
* **Connection Anchoring:** Line connectors occasionally struggle to snap cleanly to component edges.
* **Session Persistence:** Flowcharts may reset upon refreshing the page (save/export functionality coming soon).
* **Mobile Responsiveness:** Touch events on mobile devices are currently unstable. Desktop access is recommended.

*Found a bug not listed here? Feel free to submit an issue via the [Issues](https://github.com/rishabh-py3/flowchart-app/issues) tab!*
